# Workshop doc rules (from Chaklam's feedback)

Each rule has the comment that taught it. The slide rules in `../make-lecture-deck/references/rules.md` also apply; this file holds only what is special to workshop docs.

## Visuals
- **A visual wherever one helps: screenshots, diagrams, charts, tables, pictures.** A doc of only words and prompts is not enough. *"need to put screenshots, diagrams, charts, tables, pictures where possible"*
  - **Screenshots:** reuse the ones in his original handout (the chat box, the agent box, plan prices). Put each next to the sentence it shows.
  - **Diagrams:** the series, the parts of a good prompt, the follow-up loop, and each lab's flow or inputs (what goes in, what comes out).
  - **Charts:** for a lab with a data file, draw the key finding from that file, so learners can check the AI's numbers against it.
  - **Tables:** for anything compared across the same columns (tools, words, habits, requirements).
  - Every visual's title states the point, and the point is true for every data point (not "every month" when two months dip).
